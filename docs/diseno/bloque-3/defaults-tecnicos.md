# Defaults técnicos

*Lo que el agente de código tendría que inventar si no lo fijamos. Cada propuesta empieza por la decisión en una frase y luego dice qué significa. La última columna es tu respuesta en literal. Ya decidido en la especificación, y no se replantea: Go, SQLite con `modernc.org/sqlite` en WAL y un solo escritor (§7); ids aleatorios de 128 bits (§1); escritura condicionada por versión (§2); el streaming nunca reenvía errores crudos del proveedor (§6).*
